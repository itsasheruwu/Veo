1.9
15 Aug 2026

GPT-5.6 Auto routing

A new Auto route coordinates GPT-5.6 Sol, Luna, and Terra across architecture, implementation, escalation, verification, and independent review. The route records the plan used for each turn and falls back explicitly when multi-agent support or a requested model is unavailable.

Agentic, Plan, and Debug modes

The composer now provides three distinct interaction modes. Plan remains non-mutating, Debug adds an evidence-first diagnostic policy, and Agentic preserves the standard implementation workflow. Mode and route selections persist per thread, with migration support for existing Plan-mode preferences.

Live workflow and subagent visibility

A compact turn-status surface reports plan progress, changed files, Auto workflow stages, review verdicts, and active subagents. The new Subagents utility tab provides agent summaries and item-scoped transcripts, with direct navigation from collaboration activity.

Durable usage-limit continuation

Interrupted turns can resume automatically after the runtime’s reported reset window. Pending jobs are stored locally and can resume on the next launch or, with explicit macOS Login Items approval, wake Veo quietly through the bundled background helper.

Runtime and interface performance

Timeline deltas are coalesced and indexed, terminal and runtime diagnostics are bounded, file browsing and saves move off the main thread, minimap work is reused, and streamed Markdown and inline images retain stable identities. Inference cancellation and inactive-thread cleanup also receive stricter lifecycle handling.

1.8
13 Aug 2026

In-app update installation

Veo downloads release disk images in the background, reports progress in the sidebar, verifies the app signature, and installs the update without redirecting to GitHub. If the running copy cannot be replaced in place, Veo installs the verified build in Applications.

Responsive background transfers

Download and installation work now runs away from the main thread, keeping chats, the terminal, and the rest of the workspace responsive throughout an update.

Settings refinements

Settings navigation gains clearer interaction feedback, and the update and runtime status rows now use consistent alignment.

Download 1.8 · Tag v1.8.0

1.7
13 Aug 2026

Browser defaults and controls

New tabs open a native start page on the right-sidebar material. Pages identify as current Safari, request a desktop layout, and keep search, JavaScript, desktop-site, and fraud-warning preferences in Settings → Browser.

Integrated ChatGPT authentication

Account Sign In and Device Code open in Veo’s WebKit view instead of Safari or the ChatGPT Mac app. After Codex login finishes, the same tab continues to chatgpt.com so the website session and Veo’s account row stay in sync.

Credential and passkey support

The in-app browser can save and fill iCloud Keychain logins, handle HTTP authentication, and request passkey access. A Keychain control sits in the browser toolbar when AutoFill is on.

Utility panel behavior

Closing the last utility tab hides the right panel instead of spawning a Review tab. The composer keeps a usable bar when that panel is wide, dropping the send hint and shortening the model label instead of wrapping into a column.

1.6
13 Aug 2026

Unified utility panel

The old Inspector and modal Changes view are replaced by a resizable right panel with Safari-style Review, Browser, and Files tabs. Add, close, and reorder tabs from one strip, then focus the panel full-screen without losing its loaded state.

Integrated change review

Navigate staged, unstaged, conflicted, and untracked files; switch between unified and split layouts; hide whitespace-only changes; stage files or checked hunks; discard with recovery; commit; create branches; and configure an AI review inline.

Embedded browser and file editing

Workspace-scoped browser tabs support navigation, downloads, popups, uploads, viewport presets, console capture, JavaScript evaluation, and optional restoration. Files adds a searchable Git-aware tree, Quick Look previews, safe workspace HTML handoff, and native editing with autosave and external-change protection.

Persistent workspace state

Settings and Workspace now remain mounted while you move between them, avoiding expensive reconstruction of timelines, terminals, web views, and editors. Appearance settings separately control the left and right sidebar materials, including the right titlebar strip.

1.5
11 Aug 2026

Notification materials

Choose Solid, Mica, or Liquid Glass for notifications. The Notifications page now links straight to that Appearance control with a focused portal transition, so the material is easy to find and change.

Progressive chat-history loading

Codex CLI chats now hydrate from the local state database in larger, progressive pages. The sidebar begins filling immediately, avoids stale overlapping refreshes, and shows its loading state on startup.

Model and command selection

The model picker gives the GPT-5.6 family its own focused controls and moves the rest of the catalog to a second page. In the command palette, Tab and the arrow keys move through suggestions, Return uses the selected command, and Escape closes the palette.

Sidebar state indicators

Show Codex threads and Browse Archived Chats now use native checkmarks when enabled.

1.4
11 Aug 2026

Notification controls

A new Notifications settings page controls macOS turn alerts, warning banners inside Veo, a menu bar item, and completion sounds. Use the built-in sound, import one of your own, preview it before committing, or keep Veo quiet.

Independent account loading

Account identity, plan, limits, and usage now load on their own fast path instead of waiting for the full skills, plugins, apps, and MCP inventory. Refreshing Account no longer kicks off that heavier integration scan.

Slash-command navigation

Native slash commands now use purposeful glyphs at the same compact size as the existing command icon. The new /temporary command marks a fresh projectless chat as disposable before its first turn.

Installer-owned app updates

The updater now replaces the installed app through a same-folder rename, allowing Veo copies installed by PKG to update themselves without requiring direct write access to the existing bundle.

Download 1.4 · Tag v1.4.0

1.3
11 Aug 2026

Automatic cleanup of empty chats

Veo discards a new chat when the user leaves it if the chat has no started turn, timeline content, queued or unsent draft, forked children, or pinned state. Its app-managed scratch workspace is removed at the same time, while chats with meaningful state are retained.

Main-canvas materials

Appearance settings gain a Theme material control beneath the theme picker, offering the same Solid, Mica, and Liquid Glass options as the sidebar and composer. It drives the main window canvas behind both the conversation and settings panes. Solid stays the default, and Liquid Glass falls back to Mica below macOS 26.

Sidebar search layout

The expanded search field now sits directly beneath the Search button, removing unnecessary vertical space.

Download 1.3 · Tag v1.3.0

1.2
10 Aug 2026

Temporary-chat lifecycle

A chat marked temporary now removes itself once it stops being the selected chat — SQLite rows, forked children, and the app-managed scratch folder go together. Deletion defers while a turn is running or drafts are queued, and retries from turn/completed.

In-app update service

A GitHub-backed update service with a sidebar status row above the runtime state, plus a new Updates settings category. Automatic checks are on by default; automatic installs stay opt-in and are unavailable when the running bundle is not replaceable. Downloads are code-signature verified before atomically replacing the installed app.

1.1
10 Aug 2026

Projectless workspaces

Start a chat immediately without picking a repository. It runs in an isolated, app-managed workspace, and can be marked temporary before its first turn. Opening a project stays the explicit route to project-backed work, and never filters the rest of the sidebar away.

Universal installers

Builds now ship as a drag-to-Applications DMG and a standard macOS PKG, both universal for Apple silicon and Intel.

1.0
9 Aug 2026

Initial release

Veo arrives as a native, local-first macOS workspace for Codex: project-aware chats, a rich task timeline, review tools, and a docked interactive terminal — all driven by a direct local codex app-server transport with no hosted backend in between.

  • Chats from every local repository in one sidebar, with per-chat working directories.
  • Streaming responses, reasoning, plans, commands, diffs, and tool calls in an item-scoped timeline.
  • Inline approvals, permission prompts, and MCP forms.
  • A SwiftTerm-backed PTY docked beside the conversation.
  • Light / Dark / system appearance, Veo accent colors, and Solid, Mica, or Liquid Glass surfaces.
